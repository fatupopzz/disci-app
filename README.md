# disci-app

<img width="558" height="720" alt="image" src="https://github.com/user-attachments/assets/6938afdf-83cb-426e-98c2-3cd20fff692e" />


A habit-tracking app with gamification. Create missions, complete them, and earn XP to level up your rank.

Built with plain HTML, CSS, and JavaScript — no libraries or frameworks. ALSO RUNS ON NGINX

## Demo

https://youtu.be/n69axuanyfo

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/disci-app.git
cd disci-app/src
python3 -m http.server 8080
```

Open `http://localhost:8080` in your browser.
